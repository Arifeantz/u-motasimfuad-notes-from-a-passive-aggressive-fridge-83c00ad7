A single original passive-aggressive fridge note for make.fun's Notes From a Passive-Aggressive Fridge: a celery stalk abandoned in the crisper drawer for nine days at perfect humidity, which has started asking whether its owner still lives here. The program writes that one line, deterministically and with no dependencies, to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
